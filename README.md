# MSGS — Event Management & Agency

A responsive, single-page company showcase with an ivory, black and gold visual identity inspired by the MSGS visiting card.

## Run locally
Open `index.html` in a browser. This is a static website and needs no build command or API key.

## Deploy
The repository is ready for static hosting. For Vercel, use the Other framework preset, leave build command blank and set the output directory to `.`. GitHub Pages can also serve the root `index.html`.

## Website features
- Responsive navigation, hero, service list, company story, image gallery and contact section
- WhatsApp enquiry form that sends a pre-filled message (submissions are not stored on a server)
- Company logo and event images are stored in `assets/`
